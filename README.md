# Deal Smith Realty agent kit

Claude Code tools for Deal Smith Realty agents. Each one runs on **your** Mac with **your** accounts: your Claude
plan, your Messages, your GoHighLevel. Nothing uses anyone else's account or sends anything without you.

In Claude Code, add the kit once:

```
/plugin marketplace add dealsmithrealty/dsr-agent-kit
```

Then install what you want:

| Tool | Install | Then type |
|---|---|---|
| **Deal Forge**: find everyone you've texted, sort them, draft reconnect texts, work them from a dashboard | `/plugin install deal-forge@dsr-agent-kit` | `/forge-setup`, then `/forge` |
| **YouTube editor**: raw video in, finished 4K video out | `/plugin install youtube-edit@dsr-agent-kit` | `/video-setup`, then `/yt-edit <file>` |

Restart Claude Code after installing. Updates: `/plugin marketplace update dsr-agent-kit`.
Each tool's own guide is in `plugins/<tool>/README.md`.
